# Story Blueprint Runtime for Unity

Install from Unity's Package Manager with this Git URL:

    https://github.com/Cola-s-Commune/StoryBlueprint.git?path=/integrations/unity/samples/RuntimeDemo/Packages/com.storyblueprint.runtime#main

The package manifest declares Newtonsoft JSON 3.2.1 and uGUI. Package Manager resolves these
dependencies automatically. No Asset Store listing is required.

Open Runtime/Demo/SBDemoScene.unity or add Runtime/Demo/StoryBlueprintRuntimeDemo.prefab
to a scene. For another story, import compiled .storyc.json from the dockable Story Blueprint
panel and attach the package's editable StoryBlueprintStoryPlayer prefab.
