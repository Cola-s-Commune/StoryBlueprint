# Story Blueprint

[发布页与下载](https://storyblueprint.biaozi.biz:8443)

Story Blueprint 是一个面向游戏开发的可视化剧情编辑器。通过蓝图风格的节点画布，将对话、选项、条件分支、变量和游戏事件连接起来，制作可交互的故事流程。

它适合用来创作角色对话、分支剧情、任务流程、新手引导和过场演出。剧情内容与游戏引擎分离，可以在编辑器中创作和预览，再通过引擎适配器接入游戏。

- **蓝图编辑**：用节点和连线组织故事，支持子剧情复用、角色与资源管理。
- **运行预览**：直接在编辑器中体验对话与选项，检查流程和内容问题。
- **AI 辅助创作**：通过内置助手或 MCP 客户端协作编辑，在画布中预览和确认修改。
- **Ink 导入**：将支持的 Ink 内容转换为节点，也可通过 Ink Block 运行 Ink 剧情。
- **Git 协作**：以剧情内容和图结构展示差异，辅助处理多人修改产生的冲突。
- **Unity 集成**：提供 C# 剧情运行时、导入工具和示例，将编辑好的故事接入游戏。
