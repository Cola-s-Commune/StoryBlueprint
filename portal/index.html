专为游戏叙事开发者设计

摒弃繁琐的散乱配置与传统 Word 文档，以直观且专业的节点图驾驭宏大剧情分支。

蓝图级智能连线与自动排版

独家定制 BlueprintSmoothStepEdge 路由器，跨列长连线紧邻目标列正交变轨；端口感知垂直排序，实现复杂长流程 0 交叉排版。

AI 提案暂存审查沙盒 (Staging)

AI 执行蓝图修改在画布以暂存预览态呈现（新增绿、修改黄），顶部提供 Apply / Discard 审核横幅与局部邻域自动排版，安全透明。

Git 三方语义冲突合并

真正理解蓝图拓扑的冲突消解器，自动识别连通变化区域、并发插入链、执行边竞争与有序列表对齐，团队多人协作零风险。

Ink 互操作与双视图编辑

Monaco Lines 结构化视图与剧本级 Ink 文本流双向无缝实时同步，支持对白段合并拆分、说话人前缀与类型表达式插值。

强类型角色与资源闭环

角色定义强类型字段（如 Player.gold），与表情（Emotion）、立绘、语音、全局变量形成全静态引用索引，重命名与删除绝对安全。

安全防篡改更新与双通道反馈

集成 Ed25519 签名验签与流式 SHA-512 防篡改更新体系；内置用户建议与 AI 异常诊断直通 GitHub Issues 双通道快速闭环。
